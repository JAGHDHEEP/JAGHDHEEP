## Selected Work

### [Research Buddy: Evidence Desk](https://github.com/JAGHDHEEP/research-buddy-evidence-desk)
A research workflow for checking claims against uploaded papers and reports. It retrieves relevant passages, labels evidence, and exports a traceable audit record. Built on the [Research Buddy NextGen retrieval pipeline](https://github.com/JAGHDHEEP/research-buddy-nextgen).

### [Heart Disease Risk Prediction](https://github.com/JAGHDHEEP/heart-disease-risk-prediction)
An end-to-end ML project with leakage-conscious preprocessing, a FastAPI service, a Streamlit app, and per-patient SHAP explanations. [Try the live demo](https://heart-disease-risk-prediction.streamlit.app). This is an educational project, not a diagnostic tool.

### [The Data Dimension](https://github.com/JAGHDHEEP/data-dimension-portfolio)
An interactive 3D portfolio built with Next.js, React Three Fiber, and GSAP, bringing projects and data concepts together in a scroll-driven WebGL experience.

### [Factory Hazard Mitigation](https://github.com/JAGHDHEEP/Employing-YOLO-for-Distance-computation)
A computer-vision safety prototype that estimates worker-to-machine distance using YOLO and sensor input.
